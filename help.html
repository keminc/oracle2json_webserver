ora2json web service

HTTP-сервис для выполнения SQL-запросов к Oracle DB с возвратом результата в JSON.

Настройка подключений к БД

Подключения настраиваются в файле config/sql.lib.yml:

db_connections:
  - name: "DB_ALIAS_1"
    user: "db_user"
    dsn: "db-host.example.com/DB_SERVICE_1"
  - name: "DB_ALIAS_2"
    user: "db_user"
    dsn: "db-host.example.com/DB_SERVICE_2"

Переменные окружения

Пароль для каждого подключения передаётся через переменную окружения <name>_token в формате base64:

# Формат: имя подключения + _token
export DB_ALIAS_1_token="$(echo -n 'пароль' | base64)"
export DB_ALIAS_2_token="$(echo -n 'пароль' | base64)"

Если переменная не задана или невалидна — все эндпоинты этого подключения вернут HTTP 503.

Проверить статус подключений: /health

Фильтрация (query parameters)

ПараметрОписаниеПример
filterФильтр по полю. Формат: поле:оператор:значение
Используйте * вместо имени поля для поиска по всем полям		?filter=country:eq:IND
?filter=*:contains:error
fieldsВернуть только указанные поля (через запятую)?fields=name,status
sortСортировка: поле или -поле (desc)?sort=-amount
limitОграничить кол-во записей?limit=10
from / toФильтр по времени (epoch ms или ISO)?from=1700000000000&to=1700100000000
time_fieldУказать поле даты (авто-определяется если не задано)?time_field=created_at

Операторы фильтра

ОператорОписание
eqРавно (без учёта регистра)
neqНе равно
containsСодержит подстроку
gt / ltБольше / меньше
gte / lteБольше-равно / меньше-равно

Примеры запросов

GET /get-balances
GET /get-balances?fields=WALLET,BALANCE&sort=-BALANCE&limit=5
GET /all-transfers?filter=status:eq:success&limit=100
GET /all-transfers?from=1700000000000&to=1700100000000
GET /countries_enabled?filter=country:contains:Rus&fields=country,cur_iso
GET /errors_encyclopedia?filter=*:contains:timeout

Формат ответа

Массив JSON-объектов (каждый объект — строка результата SQL):

[
  {"COLUMN1": "value1", "COLUMN2": 123},
  {"COLUMN1": "value2", "COLUMN2": 456}
]

В случае ошибки:

{"ERROR": "описание ошибки"}
